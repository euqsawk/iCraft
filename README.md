# Usine fractale

Un jeu d'usine en 2D pour téléphone, joué dans le navigateur. On trace ses tapis au doigt, on pose ses machines sur une grille invisible, et un petit robot jaune construit le tout avec ses drones.

Ce dépôt contient le **premier prototype jouable** : la carte, le robot et ses drones, les machines au charbon, les tapis tracés au doigt, le Noyau et ses paliers, le Laboratoire, le Comptoir et l'arbre de déblocages.

## Jouer sur iPhone

1. Ouvre le lien GitHub Pages du dépôt dans Safari.
2. Touche **Partager**, puis **Sur l'écran d'accueil**. Le jeu s'ouvre alors en plein écran, fonctionne hors connexion et sa sauvegarde est mieux protégée.

### Menu principal et nouvelle partie

À chaque lancement (quand le jeu n'était plus en mémoire), le menu principal s'ouvre : **Continuer** la dernière partie, **Nouvelle partie**, **Parties** (3 emplacements : jouer, exporter, supprimer) et **Importer un code**. Dans le menu du jeu, **Exporter la partie** donne un code (« UF1.… », la sauvegarde compressée) à copier ou partager ; l'importer recrée la partie sur n'importe quel téléphone. « Menu principal » ramène à cet écran.

Une nouvelle partie commence par une courte présentation : « Ça, c'est toi », la personnalisation du robot (couleur, accessoire, nom), puis les drones et leurs priorités. Ensuite la caméra montre la carte de loin, plonge vers le robot, et le brouillard se referme autour de la zone de départ (toucher l'écran passe l'animation).

Pendant la partie, quelques **conseils** courts expliquent les débuts (charbon, foreuse, coffre, fer, fabrication à la main). Chacun se valide tout seul quand on l'a fait, ou avec « Compris ». « Plus de conseils sur cette partie » les coupe pour cette partie ; le menu du jeu permet de les réactiver.

### Les gestes

| Geste | Sans outil | Avec un outil |
| --- | --- | --- |
| Glisser un doigt | Déplace la caméra | Trace un tapis (repasser sur le tracé le reprend de là), pose une machine ou gomme |
| Toucher le sol | Envoie le robot | Pose la machine (outil Machine) ou gomme une case |
| Toucher une construction | Ouvre sa bulle (Déplacer, Supprimer) | — |
| Toucher le Noyau | Ouvre sa mission | — |
| Toucher le Laboratoire ou le Comptoir | Ouvre son stock ou ses commandes | — |
| Toucher le robot | Inventaire, charbon et priorité des drones | — |
| Glisser depuis le milieu d'un tapis | — | Crée une dérivation : le tapis devient un séparateur (à débloquer) |
| Deux doigts | Déplacer et zoomer | Déplacer et zoomer |

Pour poser une machine : fais glisser sa carte depuis la palette jusqu'à sa place (un simple toucher ne pose plus rien : la carte se déplace normalement pendant que la palette est ouverte). À partir de 10 machines, la palette a un sous-menu de catégories (Extraction, Fabrication, Électricité, Stockage, Outils). Pendant le glisser, pendant le glisser, la palette et les outils s'effacent et une petite corbeille rouge apparaît en bas (y lâcher la machine annule). Elle apparaît un peu au-dessus du doigt pour rester visible. Une foreuse affiche en direct ce qu'elle va extraire par seconde sur le filon visé. Là où un tapis touche une machine, un petit bloc blanc montre l'entrée (chevron rouge) ou la sortie (chevron vert). Si un tapis longe déjà une machine, trace avec l'outil Tapis depuis la machine vers ce tapis : ils sont reliés par le côté, sans nouvelle case, avec un petit bout de tapis entre les deux. Un tapis coincé entre deux machines peut être relié aux deux. Dans l'autre sens, trace depuis le milieu d'un tapis vers une machine qu'il longe : le tapis la nourrit (un objet sur deux y entre, tout si elle est seule à en vouloir). La bulle du tapis permet de couper ces liaisons. **Ponts** (branche Logistique) : en traçant un tapis, continue tout droit par-delà un autre tapis et le tien passe par-dessus (jusqu'à 4 cases enjambées, 5 pièces de plus par pont) ; les deux tapis roulent sans se mélanger. Ça marche aussi depuis un tapis collé à un autre : depuis son milieu (une dérivation qui passe par-dessus le voisin) ou depuis son bout, même en tournant. La gomme sur une case enjambée retire d'abord le pont (remboursé), puis le tapis du dessous au coup suivant. Deux machines collées se relient aussi en traçant de l'une vers l'autre : un bout de tapis identique aux autres, posé dans une petite encoche entre elles, avec un chevron vert, et les objets passent directement (on coupe la liaison dans la fenêtre de la machine). Posée (ou déplacée) sur un tapis, elle remplace les cases de tapis dessous (remboursées) : le tapis qui arrive devient son entrée, celui qui repart sa sortie. Des guides corail montrent quand elle est alignée avec ses voisines. Ce qui est hors de l'écran (machines, tapis, drones) n'est pas dessiné, mais l'usine continue de tourner. Toucher la mini-carte recentre la caméra sur le robot et la garde sur lui tant qu'on ne la déplace pas ; rester appuyé dessus ouvre la vraie carte de tout ce qui a été exploré (toucher un endroit y emmène la caméra). Les petits coffres montrent ce qu'ils gardent (une icône « mélange » s'il y en a plusieurs sortes), et l'ombre du robot passe sous les tapis. Les machines sont dessinées de haut en bas : leurs pastilles restent dans leur coin, et le nom d'une machine se cache si une autre est collée au-dessus. Pendant un tracé (tapis, câble, sous-sol), le doigt près du bord de l'écran fait défiler la carte et le tracé continue. Pendant un tracé ou un coup de gomme, une loupe en haut de l'écran montre ce qui se passe sous le doigt.

### La première usine

1. Envoie le robot sur le filon de charbon (gris foncé) : à l'arrêt, il mine tout seul.
2. **Machine → Foreuse** sur le charbon, et un **Coffre** à côté, relié par un tapis. Toute foreuse neuve sort du chantier avec 10 charbons. Une foreuse sur du charbon s'alimente toute seule : elle remplit d'abord sa propre case carburant avec ce qu'elle extrait, puis envoie le reste.
3. **Machine → Foreuse** sur le fer (gris-bleu), puis un **Four**.
4. **Tapis** : du fer jusqu'au four, puis du four jusqu'au Noyau.
5. Le robot construit chaque fantôme à son tour. Le drone va chercher le charbon dans le coffre et recharge les machines dont le voyant clignote. Le Noyau reçoit les lingots : sa mission avance.
6. Après quelques minutes, le Noyau t'offre un **Comptoir** (ses commandes rapportent des pièces), puis un peu plus tard un **Laboratoire** (il garde les objets qui débloquent l'arbre, la Presse en premier). La caméra va les voir et une carte explique leur rôle.

## Règles déjà en place

- **Recettes déduites de l'entrée** : une machine fait ce qu'on lui apporte (une presse transforme un lingot de fer en plaque, de l'aluminium en tôle…). Seule la raffinerie avec du pétrole demande un choix, dans sa bulle.
- **Tout au charbon** (jusqu'à l'électricité) : le **carburant** de la raffinerie sert comme le charbon (machines, générateur, station, robot et drones), mais il passe en priorité et dure 5 fois plus longtemps : dans une case carburant, il brûle avant le charbon ; le robot et les drones le prennent d'abord. Les jauges montrent combien de carburant la case contient, avec l'icône du carburant (et non du charbon) dès qu'il y en a ; un drone qui recharge une machine avec du carburant y met bien du carburant. Le débit réel d'une machine montre le combustible qu'elle brûle vraiment. chaque machine a une case carburant de 10 charbons ; un charbon dure 10 s de travail. Un tapis qui apporte du charbon remplit cette case. Quand elle tombe à 2, un voyant clignote sur la machine. Une raffinerie réglée sur le carburant s'alimente elle-même : ce qu'elle produit remplit d'abord sa case carburant (elle démarre même à vide), et les drones ne la rechargent plus.
- **Robot** : une case carburant (un charbon = 30 s de route, de chantier ou de minage) et 5 cases d'inventaire de 10. À l'arrêt sur un filon, il mine et garde ce qu'il trouve ; il se recharge avec le charbon de son inventaire. Sans charbon, il avance au quart de sa vitesse. Touche-le pour voir sa jauge et son inventaire.
- **Drones** : un au départ (avec 10 charbons), deux de plus à débloquer dans l'arbre (branche Robot). Chacun a une case carburant (un charbon = 20 s de vol) et une case d'inventaire. Ils construisent, rechargent les machines en charbon en priorité celles qui clignotent, vont remplir leur cargaison au coffre le plus proche. Ils ne se servent jamais dans l'inventaire du robot : ce qu'il mine reste à lui. Sans charbon, ils se posent sur le robot, qui partage avec eux la moitié de sa case carburant. Portée : 16 cases autour du robot, la même pour construire, recharger et livrer ; un disque très pâle, sous tout le reste, la montre autour du robot (il grandit avec les Antennes).
- **Coffre** (1 case, 100 objets) : un tapis peut le remplir, un tapis peut en sortir, les drones y prennent le charbon.
- **Construction** : chaque pose coûte des pièces et apparaît en fantôme. Le robot construit à courte portée, en allant de chantier en chantier ; les drones l'aident autour de lui.
- **Séparateur** (à débloquer dans l'arbre) : un objet sur deux part dans la dérivation ; si une sortie est pleine, tout passe par l'autre. Pour fusionner deux tapis, il suffit d'en faire arriver un sur le côté de l'autre. Les objets qui arrivent par le côté glissent du bord jusqu'au milieu du tapis (ils ne sautent plus). Un tapis qui longe deux machines collées de part et d'autre (une au-dessus, une en dessous) peut nourrir les deux et continuer tout droit : pars de la case vers la première machine, puis de la même case vers la seconde ; un objet sur trois va à chacune. **Tri** (Logistique, palier 3) : touche un séparateur, « Trier un objet », et choisis l'objet qui part dans la dérivation (tout le reste continue tout droit) ; une pastille montre l'objet trié sur la case.
- **Entrepôt** (Logistique, palier 6) : 3 × 3, garde 900 objets et montre en petit les neuf sortes qu'il garde le plus. **Lampadaire** (Énergie, palier 2) : une case, éclaire loin autour de lui la nuit, sans courant ni charbon.
- **Noyau et paliers** : le Noyau, carré, reçoit les tapis par n'importe quelle case de son bord. Il donne des missions fixes, les mêmes dans toutes les parties (palier 1 → 2 : 150 lingots de fer, 80 lingots de cuivre, 40 plaques de fer, environ 15 minutes ; les suivantes sont de plus en plus longues). Chaque mission terminée fait passer au palier suivant, qui ouvre une partie de l'arbre. Il prend seulement ce que demande sa mission.
- **Inventaire en grand** : toucher le robot ouvre son inventaire (charbon, 5 cases), la fabrication à la main et ses drones. Toucher un coffre ouvre son contenu avec l'inventaire du robot dessous : on choisit une pile, une quantité (1, moitié, tout, ou au curseur), puis on la donne au robot ou on la dépose dans le coffre. Une pile du robot peut aussi être séparée en deux, ou détruite (tout ou partie, avec confirmation) pour faire de la place. Toucher une machine (four, foreuse, assembleur…) l'ouvre en grand, sans rien à faire défiler : en haut, une liste déroulante « Auto » (la machine fabrique toujours selon ce qu'on lui apporte ; choisir une recette sert seulement à prévoir ses débits), puis le dessin de la machine avec ses entrées à gauche et ses sorties à droite, là où elles se branchent vraiment (en haut, en bas, sur les côtés). Sur chaque tapis relié : l'objet reçu en dernier par cette entrée (ou sorti par cette sortie) et le débit attendu d'après la recette (rien n'est mesuré ; pour le charbon, ce qu'elle brûle en travaillant). Une machine à l'arrêt parce que sa sortie est bouchée (ou venue d'une ancienne partie) les connaît quand même : ce qui attend sur ses tapis et dans ses cases suffit. La liste des recettes ouverte ne bouge plus (la fenêtre attend qu'elle se referme pour se mettre à jour) ; toucher ailleurs la referme. Une machine encore reliée à rien montre en pointillés les entrées nécessaires (avec leur débit) et, à droite, le débit maximum de sa sortie. On **glisse** une de ces cartes sur un côté du bâtiment, sur la carte du jeu : la caméra s'approche, les emplacements possibles s'allument, et lâchée, elle devient une **entrée ou sortie prévue** : un chevron sur le bord du bâtiment, sans prendre de case, en attendant le tapis (le petit × la retire ; un tapis tracé jusqu'au chevron garde l'objet prévu, même avant que rien ne passe). Dessous : le carburant ou le courant sur une ligne, l'inventaire de la machine en petit (toucher une pile la rend au robot), les liaisons directes, et le bouton « Donner depuis… » qui ouvre l'inventaire du robot (ce qui sert à la machine est en clair ; « Tout ce qui lui sert » donne tout d'un coup). Le Noyau, le Laboratoire, le Comptoir et la Revente ont aussi l'inventaire du robot dans leur fenêtre : on leur donne directement ce dont ils ont besoin (les piles qu'ils refusent sont grisées).
- **Scanner** : dans l'inventaire du robot, choisis une matière ; pendant 10 secondes, trois flèches autour du robot montrent les trois filons les plus proches (même sous le brouillard, jusqu'à 8 chunks), avec leur distance en cases.
- **Fabrication à la main** : le robot fabrique tout ce que font les machines débloquées, trois fois plus lentement, en brûlant son charbon. Il remonte les recettes tout seul (du minerai de fer aux vis : fonte, puis tournage) et prend d'abord les composants déjà fabriqués qu'il a sur lui. Jusqu'à 5 fabrications en file ; annuler rend les ingrédients.
- **Laboratoire** (unique, offert) : il garde jusqu'à 500 de chaque objet qui sert à un déblocage. Les drones lui apportent de quoi faire toutes les améliorations possibles à ce palier (y compris celles qui s'ouvrent après une autre) : quand deux nœuds demandent le même objet, leurs quantités s'additionnent. Débloquer un nœud consomme les objets demandés (par exemple 20 lingots de fer pour la Presse).
- **Station** (2 × 2, 100 pièces, à débloquer dans la branche Robot : 30 lingots de fer et 10 de cuivre) : elle a son propre drone, qui construit, recharge en charbon et livre depuis les coffres dans un rayon de 12 cases autour d'elle, même quand le robot est loin. Ce rayon s'affiche (et les machines à portée se teintent en vert) quand on la pose, la déplace ou ouvre sa fenêtre (où l'on range aussi les priorités de son drone). Sa case carburant garde 50 charbons (un tapis peut la remplir) : son drone s'y sert pour recharger les machines autour, en lui en laissant 2. Sans charbon, le drone se pose sur la station et reprend celui de sa case carburant.
- **Revente** (2 × 2, 20 pièces) : une benne où les tapis déposent ce dont on ne veut plus (400 objets au plus). Toutes les 5 minutes, un gros drone vient la vider et revend tout d'un coup, à bas prix (0,2 pièce par point de valeur : 10 lingots de fer rapportent 6 pièces, contre 80 au Comptoir). C'est une poubelle et un filet de sécurité quand on n'a plus de pièces. Pendant une absence, la benne est vendue au retour.
- **Bâtiments offerts** : le Comptoir et le Laboratoire ne sont pas dans la palette. Le Noyau les pose près de lui (Comptoir après la première livraison au Noyau ou 4 minutes de jeu, Laboratoire 2 à 5 minutes plus tard). On peut les déplacer, pas les supprimer.
- **Comptoir** (unique, offert) : il reprend les commandes au choix (3 propositions, relance contre des pièces) ; une commande livrée rapporte des pièces, c'est la source d'argent. Une commande en cours peut être abandonnée (en deux temps) : ce qui a déjà été livré est perdu et trois nouveaux choix arrivent.
- **Priorités des drones** : dans la bulle du robot, touche un drone pour ranger ses cinq tâches (recharger le charbon, construire, livrer le Noyau, le Laboratoire ou le Comptoir), de la plus importante à la moins importante. Il fait la première tâche utile de sa liste ; son propre charbon passe toujours avant. Un drone ne prend dans un coffre que la quantité dont le bâtiment a besoin. « Même ordre pour tous » copie la liste sur les autres drones. Sans travail, un drone se pose sur le robot (qui le porte) ou sur sa station et ne brûle plus de charbon ; il redécolle dès qu'il y a quelque chose à faire. Pour livrer, les drones se servent uniquement dans les coffres ; une cargaison dont plus personne ne veut retourne dans le coffre d'où elle vient (ou est détruite si ce coffre n'existe plus ou est plein), jamais dans une machine ni dans un autre coffre.
- **Supprimer** rembourse 100 % (bulle ou gomme). La **Gomme** a deux modes : **Gomme** (case par case, au doigt) et **Zone** : on encadre une zone au doigt (la carte défile au bord de l'écran), ce qui partira est surligné, et un bandeau demande confirmation avant de tout supprimer (machines, tapis, câbles ; le Noyau et les cadeaux restent).
- **Arbre de déblocages** : cinq branches, Production (machines), Logistique (séparateur, tapis rapide et express, grand coffre de 2 × 2 qui garde 300 objets et montre en petit ce qu'il contient…), Robot (deuxième et troisième drones, Station, **Antennes** I à III : les drones du robot vont 1,5, 2 puis 2,5 fois plus loin ; **Chenilles** I à III : le robot roule 1,25, 1,5 puis 2 fois plus vite), Énergie et Modules. Chaque nœud s'ouvre à un palier et se paie en objets déposés au Laboratoire. Touche ton palier en haut à gauche pour l'ouvrir ; un point rouge signale qu'un nœud est prêt. Dans chaque branche, une ligne par palier (cochée quand il est passé, surlignée pour le palier en cours, avec un cadenas pour les suivants) ; un palier qui a besoin de plus de place prend plusieurs lignes et pousse les suivants vers le bas, et un palier qui n'ouvre rien dans cette branche n'apparaît pas. Les nœuds pas encore ouverts gardent leur cadre (sur la ligne de leur palier, avec un cadenas) mais cachent ce qu'ils débloquent : un « ? », un nom en « ??? » ; leur fiche dit seulement comment les ouvrir (palier, ou déblocage précédent, sans nommer ceux qui sont encore cachés).
- **Bulle d'une machine** : elle montre ce que la machine attend en entrée et ce qu'elle renvoie en sortie, recette par recette. Les entrées et sorties prévues (glissées depuis sa fenêtre) sont des chevrons dans une pastille blanche sur son bord ; un tapis tracé jusque-là les remplace.
- **Biomes** : le sol est dessiné à 4 pixels par case, avec des bords nets et arrondis entre les biomes (plus de marches floues où deux couleurs semblent se chevaucher).
- **Carte infinie** générée par une graine (visible et copiable dans le menu), avec brouillard (on peut construire dedans : machines, tapis et câbles), biomes et filons pauvres, normaux ou riches.
- **Sauvegarde** automatique dans le navigateur (IndexedDB), toutes les 10 secondes et à la fermeture, dans l'emplacement de la partie. Les mises à jour gardent la partie (et la relancent directement). L'ancienne partie unique est reprise dans le premier emplacement.
- **Absence** : quand le jeu est fermé, l'usine tourne à 10 % de sa vitesse, sur 8 h au plus. Ce que les tapis livrent au Noyau, au Laboratoire et au Comptoir compte ; un écran au retour montre ce qui a été livré.
- **Mise à jour** : le menu propose « Chercher une mise à jour ».

- **Compteur** (10 pièces, dans la palette) : il se pose sur un tapis, sans rien remplacer. Un petit portique enjambe le tapis et une étiquette affiche son débit (« 1,2 /s », avec la matière principale), calculé sur les 20 dernières secondes ; un tapis à l'arrêt retombe donc doucement à 0. La bulle du tapis donne le détail par matière. La gomme retire le compteur avant le tapis.
- **Camions et trains** (Logistique, paliers 4 et 5) : on pose des **Dépôts** (camions, 120 pièces) ou des **Gares** (trains, 250), en 2 × 2, depuis la catégorie Transport de la palette. Chacun a **deux coffres** de 300 objets : les **départs**, remplis par les tapis qui y arrivent (et les drones, ou le robot), partent avec les véhicules ; les **arrivées** reçoivent ce que ramènent les véhicules et ressortent sur les tapis qui partent du dépôt (les drones et le robot s'y servent aussi). Ce qui arrive ne repart donc jamais tout seul, et ce que les tapis apportent ne ressort pas par les tapis. La fenêtre du dépôt montre les deux coffres ; le robot peut prendre dans l'un ou l'autre, et déposer dans les départs ou les arrivées. Dans la fenêtre d'un dépôt, « Relier à un autre dépôt » ouvre la carte : on touche l'arrêt d'arrivée, une route à deux voies (ou une double voie ferrée) est posée en L entre les deux : les véhicules roulent à droite et se croisent sans se gêner, à l'aller comme au retour sur le même L et un premier véhicule fait les allers-retours (camion : 20 objets, 4 cases/s, 150 pièces ; train : 80 objets, 7 cases/s, 400 pièces ; route 2 pièces la case, rails 5). La fenêtre de la ligne (bouton **Transport**, ou « Gérer » depuis un dépôt) règle pour chaque arrêt ce que le véhicule y **dépose** et ce qu'il y **prend** (Rien, Tout, ou une liste d'objets choisis) : on envoie par exemple du carburant à une grande foreuse lointaine et on ramène son minerai dans le même voyage. À un arrêt, il dépose d'abord, puis charge, sans jamais reprendre ce qu'il vient d'y laisser ni redéposer ce qu'il vient d'y prendre. Elle ajoute des arrêts (6 au plus, la ligne se parcourt en boucle dans l'ordre) et en retire (×, 2 au minimum), ajoute ou retire des véhicules (6 au plus) pour aller plus vite, et ferme la ligne (remboursée). Un seul véhicule à quai par dépôt (ou gare) : les autres attendent leur tour sur la route, devant l'entrée, à la file sans se chevaucher.
- **Électricité** (branche Énergie, palier 4) : le **Générateur** brûle du charbon (les drones le rechargent) et fournit **600 kW** ; il ne brûle que pour ce qui est consommé (un charbon = 10 s à pleine charge). Chaque machine au courant consomme selon sa taille quand elle travaille : 60 kW (presse, tour, tréfileuse), 90 kW (foreuse, four), 120 kW (broyeur, mélangeur), 150 kW (assembleur), 180 kW (fourneau), 250 kW (raffinerie), 300 kW (fabricant), 400 kW (centrifugeuse). La fiche du générateur montre les kW demandés sur les kW fournis, celle d'une machine sa consommation et son courant. Il débloque l'outil **Câble** : on le trace au doigt comme un tapis, il passe sous les tapis et les machines (2 pièces la case, posé tout de suite), et un câble alimente les machines **à 5 cases autour de lui** (dessous compris) : chaque machine se branche sur le câble le plus proche, sans relier deux réseaux entre eux (seuls les câbles relient). Un câble est jaune quand son réseau a du courant. Les câbles sont cachés hors du mode câble (la gomme les montre, pour voir ce qu'on efface). Prendre l'outil Câble passe en **mode électricité** : la surface pâlit sous un voile bleu nuit, les câbles se voient par-dessus les blocs, les machines alimentées (et les générateurs qui tournent) sont jaune vif avec un éclair, celles branchées sans courant en gris bleu, celles qui pourraient se brancher en pointillés, et la portée des câbles posés est teintée. Pendant le tracé d'un câble, sa portée s'affiche en jaune avec son contour, et les machines qu'il alimentera sont cerclées de jaune. Ensuite, chaque type de machine se débloque **au courant** (Foreuse, Four, Broyeur, Presse, Tréfileuse, Mélangeur, Tour, Fourneau, Raffinerie, Assembleur, Fabricant, Centrifugeuse) : ce n'est pas une nouvelle machine, ce sont tes machines (déjà posées ou à venir) qui se branchent dès qu'un câble les touche. Alimentée, une machine ne brûle plus de charbon, n'en demande plus aux drones et porte un petit éclair ; si le générateur s'arrête, elle reprend son charbon, et sans charbon ni courant elle affiche la pastille éclair. Trop de machines pour un réseau : elles ralentissent. Le générateur montre la charge de son réseau, une machine branchée son courant. Les anciennes « machines électriques » des sauvegardes redeviennent des machines normales. La gomme retire un câble en dernier (après ce qui est posé dessus).
- **Jour et nuit** : un cycle de 8 minutes (environ 5 min de jour, un crépuscule, 2 min de nuit, une aube) ; un petit soleil ou une lune dans le coin de la mini-carte. La nuit, la carte s'assombrit en bleu nuit (une carte de lumière posée en mode « multiplier » : ce qui est éclairé garde ses vraies couleurs) ; chaque bâtiment construit fait une flaque de lumière chaude autour de lui (un peu plus quand il travaille, le Noyau en rouge orangé), le robot porte un halo et le faisceau de sa lampe dans la direction où il roule, et les camions et les trains allument deux gros phares qui éclairent la route devant eux. Le robot se tourne là où il roule (il regarde à gauche ou à droite et penche vers le haut ou le bas, en douceur). Pas de nuit dans un atelier. **Panneau solaire** (Énergie, palier 5) : 120 kW gratuits en plein jour, moins au crépuscule, rien la nuit. **Batterie** (palier 5) : garde le surplus du soleil (10 kWh, 200 kW au plus en charge comme en décharge) et le rend quand il manque. Sur un réseau, le soleil sert d'abord, puis les batteries, puis le charbon des générateurs (qui ne brûlent que pour le reste) ; la fiche montre le soleil, les kWh gardés et la charge du réseau.
- **Eau et réacteur** (Énergie) : des **lacs** (un près du départ, d'autres en plaine et dans les marais). La **Pompe à eau** (palier 5) se pose sur un lac et envoie 40 L/s dans les **tuyaux** (outil Câble → Tuyau, 3 pièces la case) ; un tuyau relie les machines qu'il touche (dessous ou à côté). Un **Mélangeur** arrosé travaille moitié plus vite (5 L/s). Le **Réacteur** (3 × 3, palier 7) donne 2,4 MW avec des barreaux d'uranium enrichi apportés par tapis (un barreau = 2 minutes à pleine charge) ; sans eau (20 L/s), il s'arrête. Sur un réseau : le soleil, puis les batteries, puis le réacteur et les générateurs. **Hangar** (Robot, palier 4) : une station de 3 × 3 à trois drones. **Recharge des drones** (Robot, palier 5) : reliée au courant (80 kW), les drones autour viennent s'y recharger au lieu de brûler du charbon.
- **Grand Nord et fusée** : loin du départ (au-delà de 240 cases), des **toundras** enneigées cachent du **titane** et du **cristal pur**. Le four fond le titane en lingots, le fourneau en fait de l'**alliage** (avec de l'acier), la presse taille le cristal en **lentilles** ; le fabricant assemble **structures de fusée**, **moteurs de fusée** et **guidages**. **Paliers 9 et 10** : le Noyau veut de l'alliage, des lentilles et des ordinateurs, puis les pièces de la fusée. Au palier 10, la **Rampe de lancement** (4 × 4) : remplis-la (20 structures, 8 moteurs, 4 guidages, 100 carburants) par tapis ou depuis l'inventaire du robot ; après 5 secondes de compte à rebours, la fusée décolle dans la fumée, et on peut recommencer. **Monte-charge** (Modules, palier 9) : posé dans un atelier, l'atelier se sert dans les coffres collés à lui dehors (ce que son intérieur sait utiliser) et y range ce qui sort.
- **Météo** : un temps toutes les 200 secondes, tiré de la graine (clair le plus souvent) ; une petite icône dans le coin de la mini-carte. La **pluie** (traits à l'écran) ralentit les camions de 30 % et voile un peu le soleil ; la **neige** (flocons) divise par deux les panneaux solaires. **Pollution** : chaque charbon brûlé salit le sol de son morceau de carte (un générateur plus qu'une machine) ; un voile brun la montre. Au-delà d'un seuil, les machines ralentissent (jusqu'à 40 %) et le soleil passe moins. Elle retombe lentement d'elle-même ; les **Arbres** (une case, palier 2) la nettoient doucement, le **Filtre à air** (au courant, 60 kW, palier 5) vite. **Plans** : dans la fiche d'un atelier, « Enregistrer comme plan » ; le plan apparaît dans la palette (Modules) de toutes tes parties sur cet appareil, à glisser sur la carte (prix de l'atelier plus son contenu au taux de copie ; il faut avoir débloqué ses machines). Le petit × l'oublie.
- **Grande foreuse** (Production, palier 6) : 4 × 4, posée au milieu d'un filon, elle l'exploite en entier, autant que des foreuses partout dessus, sans perte (0,5 objet par seconde pour 4 cases du filon, selon sa richesse). Un filon exploité par une grande foreuse est à elle seule, et elle ne se pose pas sur un filon où il y a déjà des foreuses. Elle passe au courant avec les foreuses (400 kW). Lampadaires et arbres sont posés tels quels, sans socle ni nom.
- **Modules** (branche Modules, palier 5) : l'outil **Module** entoure au doigt des machines (et leurs tapis) ; on confirme et elles se rangent dans un **Atelier** de 3 × 3 (200 pièces) posé au milieu de la zone, qui produit pareil. Les tapis qui entraient dans la zone arrivent dedans par une **Entrée**, ceux qui en sortaient repartent par une **Sortie** ; on rebranche dehors les tapis sur l'atelier. Toucher l'atelier ouvre sa fiche (contenu, charbon ou courant, ce qui attend à l'entrée et à la sortie) : **Entrer** montre l'intérieur (une pièce de 20 × 20 cases, 24 puis 30 avec Place +4 et +6) où l'on construit tout de suite, sans robot (pas de foreuse, station, générateur ni dépôt dedans ; Entrée et Sortie se posent seulement là). Une Entrée ne fait sortir que ce que la machine au bout de son tapis sait utiliser. L'atelier brûle du charbon pour chacune de ses machines qui travaille (ou prend leur courant : la somme de leurs kW). **Copier** pose une copie vide au prix de l'atelier plus ce qu'il contient à 100 %, puis 75, 50 et 25 % avec les déblocages Copie. **Imbrication** : des ateliers dans les ateliers (on entre de l'un dans l'autre, Sortir remonte d'un cran). Supprimer un atelier rend aussi ce qu'il contient.

- **Trieur** (20 pièces, débloqué avec Tri, palier 3) : il se pose juste à la sortie d'un coffre, d'un dépôt, d'une gare ou d'une machine : sur une case libre collée au bâtiment (le tapis qu'on pose ensuite part déjà trié, rien d'autre n'y sort) ou sur la première case d'un tapis qui en part, sans rien remplacer. Sans tapis, il se montre sur un petit socle ; touche-le pour changer son choix. Un bâtiment posé dessus le remplace (remboursé). Seuls les objets choisis (plusieurs possibles) sortent par ce tapis ; le reste attend ou sort par un autre tapis. Au moment de le poser, la liste s'ouvre (ce que contient la machine en premier) ; on la rouvre en touchant le tapis. Un portillon rouge en travers du tapis et une pastille montrent l'objet choisi. La gomme le retire avant le tapis (remboursé). Exemple : une gare pleine de carburant et de minerai qui arrivent, un trieur « carburant » sur le tapis vers les machines.
- **Recettes** (menu du jeu → « Toutes les recettes ») : tout ce que tes machines savent faire, machine par machine (avec la durée), et les filons découverts pour la foreuse. La liste s'allonge à chaque déblocage ; une recherche filtre par objet, et les machines encore verrouillées sont rappelées en bas, une par ligne sur toute la largeur : celles qu'on peut débloquer maintenant avec leur nom, leur nombre de recettes et leur palier ; les autres restent cachées (« ? », « ??? ») avec seulement leur palier, comme dans l'arbre.
- **Plus de sous-sol** : les tapis souterrains (et la vue du sous-sol) ont été retirés. Une ancienne partie récupère leur prix au chargement, et le nœud disparaît de l'arbre.
- **Fenêtres du bas** : quand leur contenu est tout en haut, on les tire vers le bas du doigt ; elles suivent le geste et se ferment si on tire assez loin (ou vite), sinon elles reviennent en place. Le geste peut commencer au milieu d'un défilement vers le haut.
- **Statistiques** (menu) : chaque objet fabriqué ou extrait, avec son débit par minute (dernière minute et 5 dernières), le total depuis le début et une petite courbe des 10 dernières minutes. **Succès** (menu) : 16 objectifs (premier lingot, mille plaques, première nuit, au courant, usine dans l'usine, fractale, dix mille objets…), cochés tout seuls avec un message.
- **Parties d'essai** : `node --experimental-strip-types --no-warnings scripts/demo-saves.ts` génère des codes de partie à différents paliers (2, 4, 5 et fin), à coller dans « Importer un code ». Chacune a une base déjà construite qui tourne (lignes de fer et de cuivre, charbon au tapis vers les stations ; puis générateurs et câbles, engrenages ; puis camion et ciment ; puis train et plastique), posée par `scripts/demo-bases.ts` (places cherchées autour de repères, tapis routés case par case) ; le script vérifie que chaque chaîne produit. `scripts/demo-debug.ts <palier> <secondes>` affiche la base en carte texte.

## Développement

```bash
npm install
npm run dev        # http://localhost:5173, reconstruit à chaque modification
npm test           # tests de la simulation (sans navigateur)
npm run typecheck
npm run build      # produit dist/
```

Ajouter `?debug` à l'adresse expose `window.__game` et `window.__renderer` dans la console.

Chaque poussée sur `main` lance les tests puis publie `dist/` sur GitHub Pages (`.github/workflows/deploy.yml`).

### Organisation

| Dossier | Rôle |
| --- | --- |
| `src/data` | Objets (46, fusée comprise), machines et recettes, missions des paliers, arbre de déblocages |
| `src/world` | Graine, bruit, biomes, filons, brouillard |
| `src/sim` | Simulation pure, sans rendu : usine, tapis, tracé au doigt, robot, drones, paliers, commandes |
| `src/render` | Rendu PixiJS dans le style Pastel |
| `src/input` | Gestes tactiles |
| `src/ui` | Interface HTML (menu principal, présentation, conseils, barre du haut, outils, bulles, feuilles) |
| `src/save` | Sauvegarde IndexedDB (3 emplacements) et codes d'export |
| `tests` | Tests de la simulation |

La simulation n'importe jamais PixiJS : elle se teste seule et pourra calculer la production hors ligne.
